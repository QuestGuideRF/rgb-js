# 🎨 Интерактивный RGB Миксер

Интерактивное веб-приложение для смешивания цветов RGB в реальном времени с помощью движения мыши.

## 📋 Описание

RGB Миксер - это визуальный инструмент, который позволяет пользователям создавать и исследовать цвета RGB, просто перемещая мышь по экрану. Приложение динамически изменяет цвета в зависимости от положения курсора, создавая интуитивный и увлекательный способ работы с цветом.

## ✨ Особенности

- **Интерактивное смешивание цветов**: Движение мыши генерирует уникальные RGB-комбинации
- **Реальное время**: Мгновенное обновление цветов при движении курсора
- **Визуальная обратная связь**:
  - Большой цветовой дисплей
  - RGB и HEX значения
  - Координаты мыши
  - Индикаторы компонентов RGB
- **Адаптивный дизайн**: Работает на всех устройствах
- **Современный UI**: Красивый интерфейс с эффектами стекла и градиентами

## 🎯 Логика работы

### Алгоритм смешивания цветов:

1. **Красный компонент (R)**: Определяется горизонтальным положением мыши (X-координата)
   - Левый край экрана = 0 (минимум красного)
   - Правый край экрана = 255 (максимум красного)

2. **Зелёный компонент (G)**: Определяется вертикальным положением мыши (Y-координата)
   - Верх экрана = 0 (минимум зелёного)
   - Низ экрана = 255 (максимум зелёного)

3. **Синий компонент (B)**: Рассчитывается на основе расстояния от центра экрана
   - Центр экрана = 0 (минимум синего)
   - Углы экрана = 255 (максимум синего)

## 🚀 Как запустить

1. **Скачайте все файлы** в одну папку
2. **Откройте `index.html`** в любом современном браузере
3. **Начните двигать мышью** по экрану для смешивания цветов!

### Требования
- Современный веб-браузер (Chrome, Firefox, Safari, Edge)
- JavaScript должен быть включён
- Разрешение экрана: любое (адаптивный дизайн)

## 🎮 Как использовать

1. **Откройте приложение** в браузере
2. **Двигайте мышью** по экрану:
   - Влево-вправо: изменяет красный компонент

3. **Наблюдайте** за изменениями:
   - Основной цветовой дисплей
   - RGB и HEX значения
   - Координаты мыши
   - Индикаторы компонентов

### Формулы расчёта:
- **Red**: `(mouseX / screenWidth) * 255`
- **Green**: `(mouseY / screenHeight) * 255`
- **Blue**: `(distanceFromCenter / maxDistance) * 255`
